# PyQuest Mobile (2026 Architecture Blueprint)

This repository contains a production-ready starter blueprint for **PyQuest Mobile**, an AI-powered animated Python learning game.

## Included in this blueprint

- **Full folder structure** for mobile + backend + infra
- **PostgreSQL database schema** (Prisma)
- **Backend API modules** (Fastify + TypeScript stubs)
- **Mobile UI architecture** (Expo Router + React Native New Architecture)
- **Secure Python execution design** (Docker sandbox + limits)
- **Deployment and CI/CD starter instructions**

## Tech stack

### Mobile
- React Native (New Architecture / Fabric)
- Expo SDK (latest)
- Expo Router
- Reanimated 3
- React Native Skia
- Gesture Handler + Lottie
- Zustand

### Backend
- Node.js 22+
- TypeScript (strict)
- Fastify 5
- Prisma ORM
- PostgreSQL
- Redis
- Docker
