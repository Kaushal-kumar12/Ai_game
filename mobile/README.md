# PyQuest Mobile App (Expo + React Native)

This directory defines the recommended app layout for a high-performance animated game-learning experience.

## Key packages
- expo-router
- react-native-reanimated
- @shopify/react-native-skia
- lottie-react-native
- react-native-gesture-handler
- zustand

## Routing map
- `app/(auth)` – login/signup/guest
- `app/(tabs)` – home/map/challenges/profile
- `app/lesson/[lessonId].tsx` – coding lesson mission
- `app/challenge/[challengeId].tsx` – challenge node
- `app/cyber/[missionId].tsx` – cybersecurity missions
- `app/multiplayer/[roomId].tsx` – live coding duel room
